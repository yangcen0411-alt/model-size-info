# 模型占用信息 · SketchUp 插件

版本：1.4.1（开发版）

[下载插件安装包（RBZ）](https://github.com/yangcen0411-alt/model-size-info/raw/refs/heads/main/downloads/model_size_info_v1.4.1.rbz) · [下载源码包](https://github.com/yangcen0411-alt/model-size-info/raw/refs/heads/main/downloads/model_size_info_v1.4.1_source.zip)

这是一个独立浮动面板。默认界面只显示当前模型上次保存的文件大小和群组、组件列表。展开箭头查看子项，点击所需行的 **计算大小**，原按钮位置就显示 KB / MB。点击数值可以重新计算。

**1.4.1 调整打开和展开时的层级读取**。每层图元按小批次检查，扫描时显示当前层进度，可停止并点击“继续读取”恢复。读取期间编辑模型会中止旧的遍历，事务完成后刷新目录。

**1.4.0 简化界面**。组件列表改成单行，统计、排序、批量操作以及“查看所选对象 / 查看整个模型”统一放进右上角 **更多**。默认窗口缩为 380 × 560，可继续缩放。已有安装会保留 SketchUp 记录的窗口位置和尺寸。独立工具栏的绿色立方体按钮继续用于打开面板。

## 安装和打开

适用于 SketchUp 2022 及更新的桌面版；不适用于网页版。采用这些版本公开的 Ruby API 开发，尚未完成 SketchUp 界面内的实际验证。

1. 下载 `model_size_info_v1.4.1.rbz`，保留 `.rbz` 后缀，无需解压。
2. 在 SketchUp 中打开 **扩展程序管理器**，点击 **安装扩展程序**，选择这个文件。不同版本可能将管理器放在“窗口”或“扩展程序”菜单中。
3. 点击独立工具栏中的绿色立方体按钮打开面板，也可使用 **扩展程序 → 模型占用信息** 或建模区域右键菜单。Windows 中可在 **视图 → 工具栏** 勾选 **模型占用信息** 显示工具栏。
4. 在默认的组件树中展开目录，点击所需行的 **计算大小**。

这是未经过 Extension Warehouse 签名的开发版。如果 SketchUp 要求批准该扩展，请在管理器中手动批准此插件。无需更改全部扩展的加载策略。

从旧版升级时，安装新版 RBZ 后重新启动 SketchUp。扩展管理器中的名称为“模型占用信息”，在面板右上角打开 **更多**，底部版本应为 **v1.4.1**。

## 如何使用

通过 **更多 → 查看所选对象** 可打开跟随选择的属性视图。点击顶部 **返回列表** 回到组件树。

| 操作 | 显示内容 |
| --- | --- |
| 选择一个群组或组件 | 它的独立 SKP 文件大小、实例名称、类型、当前层内部图元数、模型中的实例数 |
| 选择同一组件的多个实例 | 相同定义只测量并计算一次 |
| 多选不同组件 | 各定义的独立文件大小，按体积从大到小排列，并显示合计 |
| 点击空白处取消选择 | 整个模型的上次保存文件大小 |
| 更多 → 查看整个模型 | 保持当前选择，同时查看模型大小 |
| 点击“返回列表” | 先读取顶层群组和组件；展开时再读取子层级 |
| 点击行内“计算大小” | 仅计算该定义的完整文件体积，包含嵌套内容 |
| 点击行内大小数值 | 更新该定义的结果，并保留其他定义的缓存 |
| 点击“测量当前模型” | 临时保存当前模型副本，测量包含未保存修改的大小 |
| 取消“自动计算选择” | 选择后只更新属性，需要点击按钮才导出测量 |
| 点击右上角刷新 | 清除缓存并刷新；小范围选择在自动模式下会重新测量 |

“跟随选择”的自动模式在选择稳定约 0.6 秒后开始测量，最多自动测量 3 个不同定义。选择更多不同定义时，点击“测量选中定义”开始。大型组件的单次副本保存由 SketchUp 同步执行，可能需要短暂等待。“停止后续任务”取消尚未开始的任务。

## 使用组件树

1. 打开面板先显示顶层目录，每行只有名称和 **计算大小**。展开和定位不会自动计算大小。
2. 点击左侧箭头读取下一层。同一定义的其他实例复用已读层级。
3. 点击 **计算大小**，完成后同一位置显示数值，例如 **18.60 MB**。点击数值可重新计算。失败时显示 **重试**。同一定义的其他实例同步更新。
4. **父组件的完整 SKP 体积包含其嵌套内容**。需要子项的单独数值时，再计算子项。
5. 点击名称可选择并缩放到对象。嵌套对象会打开父级编辑环境，父级锁定时会显示提示。悬停名称可查看完整名称、类型以及隐藏或锁定信息。
6. 右上角 **更多** 中提供排序、收起全部、读取全部层级和批量计算。统计数字、读取耗时和说明也放在这里。点击空白处或按 Esc 关闭菜单。
7. 每层默认按大小优先排列，计算中保持顺序，完成后更新。每层一次显示 100 项，可点击“再显示”继续查看。长列表在列表区域内滚动。
8. 任务执行时显示 **停止后续任务**，可停止尚未开始的工作。读取暂停后点击 **继续读取**，会接着完成已请求的层级。需要批量计算时使用“更多”里的对应操作。

树中包含隐藏和锁定对象；未使用的定义不会被遍历，也不单列面、线和图片。这些图元仍包含在所属群组/组件的完整文件大小里。

**父级大小包含子级内容，逐层相加会重复计入子级。** 数值表示各定义独立保存的 SKP 体积。

结果在当前面板会话中缓存，相同定义共享。修改模型会清除大小缓存并重新读取层级，点击右上角刷新也可重新读取。切换文档或关闭面板会取消未完成的任务。

### 扫描速度与测量速度

1.4.0 及以前的按需层级功能在每层开始时，先完整执行两次类型筛选，再分批生成条目。密集的面和线可能让这一步长时间占用 SketchUp。

1.4.1 将当前层的原始图元读取也放入分批任务。使用可续读的 `Entities#each` 遍历，每轮以 8 毫秒或 1000 次图元访问作为让出条件，每轮之间通过 25 毫秒的定时器继续。面和线只做类型判断，随即跳过，列表中保留群组和组件。当前层读取进度会显示在底部。对象编号排序在界面中完成。

读取期间监听当前图元集合的变化，发现新增、修改或删除时中止旧遍历。事务完成后由模型监听刷新目录。读取完成、关闭面板或切换文档时会移除临时监听。暂停后的“继续读取”恢复已有任务。

打开未变化的组件树会复用目录，面板接收结构和大小的变化部分。“更多”中显示最近一层的读取耗时。单次宿主 API 调用的耗时仍由 SketchUp 执行，8 毫秒是调度预算。

计算大小仍使用同步的 SKP 副本保存。计算单个大型组件可能需要等待，停止按钮会取消尚未开始的任务。尚未使用用户的实际大模型计时，验证范围见下文。

## 大小的含义

- **群组和组件**：通过官方 `ComponentDefinition#save_copy` 将定义临时保存成当前 SketchUp 格式的 SKP，再读取实际文件字节数。包含定义中的几何、嵌套对象、材质和相关数据。实例外层的材质、缩放等覆盖不在组件定义中，因此不计入该数值。
- **同一组件多次复制**：实例共享组件定义，所以不会按实例数量直接乘算大小。
- **不同定义合计**：每个定义独立导出的文件大小之和。不同文件中可能重复包含共享的嵌套组件、材质及文件头，所以它不是“合并后精确体积”，也不表示删除这些对象后原模型会减小多少。
- **整个模型**：默认读取原 SKP 在磁盘上的大小，明确标记未保存修改；点击按钮后通过 `Model#save_copy` 测量当前模型副本。不会覆盖原 SKP。
- **散线、面和图片等**：没有独立的组件 SKP 文件。请先手动创建群组或组件再测量；混合选择时只显示可测定义明细，不显示误导性的完整合计。
- **单位**：1 KB = 1024 字节，1 MB = 1024 KB。显示的是文件体积，与内存占用及模型的长宽高不同。

临时副本在测量结束或失败后自动清理。插件不会自动清理模型、重组几何、让组件唯一化、覆盖原文件或更改组件源路径。SketchUp 官方文档记录了 2027 以前保存组件副本可能更新定义 GUID 的问题；依赖 GUID 做外部追踪的工作流应留意这一宿主程序行为。

面板是可移动、可缩放的独立窗口，不属于默认托盘中的原生“图元信息”面板。

## 验证情况

已使用 SketchUp 2026 随附的 Ruby 3.2.2 通过源码语法检查和 128 项隔离逻辑检查，并使用 Node 通过 73 项面板检查。独立浏览器回放了 Ruby 面板实际生成的消息，验证密集层级的读取进度、暂停和继续，以及单行计算、共享结果、焦点恢复、“更多”菜单、属性视图返回列表、分页滚动、380 / 440 / 320 像素布局及 12 层嵌套。SketchUp 内真实模型的导出和速度尚待实测。详见 [验证记录](TEST_RESULTS.md)。

工具栏另通过 10 项隔离检查，覆盖命令注册、按钮回调、重复加载、位置/显隐恢复及 Windows SVG、macOS PDF 图标路径。图标已做 SVG 解析和单页 PDF 渲染检查，工具栏在 SketchUp 宿主中的显示尚待实测。

性能回归保留 3700 个不同定义的按需层级场景，另加入百万条原始图元的模拟集合。禁止整层筛选、复制集合及逐项按索引读取，检查首次小批次返回、时间预算、共享遍历、暂停继续、图元变更和过期任务处理。

## 源码结构

```text
src/
  model_size_info.rb              扩展注册入口
  model_size_info/
    main.rb                      菜单入口
    analyzer.rb                  定义去重、文件测量和缓存
    component_tree.rb            按需层级读取、共享缓存与对象路径验证
    panel.rb                     面板、监听和测量队列
    ui/
      panel.html
      panel.css
      panel.js
      tree.js                    按需展开、排序、分页与行内计算
tests/
  logic_test.rb
  tree_test.rb
  ui_test.cjs
```

使用可用的 Ruby 2.7+ 执行 `ruby tests/tree_test.rb`（42 项原有检查和 86 项组件树检查），使用 Node 执行 `node tests/ui_test.cjs`。插件不依赖第三方 Ruby gem、网络服务或账号。

工具栏检查使用 `ruby tests/toolbar_test.rb`。

重新打包：在项目根目录执行 `python build.py --output-dir dist`，即可生成安装包和源码包。也可以将 `src/` 里面的 `model_size_info.rb` 与同名文件夹放在 ZIP 根目录，再将扩展名改为 `.rbz`；不要把 `src/` 文件夹本身作为压缩包最外层。
